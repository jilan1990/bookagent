# 《从零实现 Harness Agent》

> 一本手把手教你从零开始构建 AI Agent 执行框架的实战书籍

## 内容简介

本书以一个真实可运行的 `mini_agent.py`（约 200 行）为线索，带你从第一行代码开始，逐步实现一个完整的 **Harness Agent**——即承载大语言模型的"执行骨架"：它负责组织提示词、驱动 ReAct 循环（Thought → Action → Observation）、调度工具、解析输出、处理异常，最终让大模型从"会聊天"进化为"会干活"。

全书不求覆盖所有框架（LangChain、AutoGPT 等），而是坚持"从零实现"：只用 Python 标准库 + 一个 HTTP 客户端 + 大模型 API，把 Agent 的每一层机制亲手写一遍。读完后，你不仅理解 Agent 的原理，更拥有一个可以自己魔改、扩展的私有框架。

## 你将学到

1. **Agent 与 Harness 的本质区别**：模型是大脑，Harness 是身体
2. **ReAct 范式**：Thought → Action → Observation 循环的完整实现
3. **工具系统设计**：如何用 JSON Schema 描述工具并让模型正确调用
4. **输出解析的工程艺术**：正则、容错、与模型的"契约"
5. **可观测性**：用 httpx 事件钩子打印每一次请求/响应
6. **工程化进阶**：配置管理、上下文控制、多工具扩展、测试与部署
